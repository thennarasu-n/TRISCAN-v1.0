🛡️ TRISCAN — Cybersecurity Toolkit

TRISCAN is a Python-based cybersecurity toolkit that combines network scanning, website analysis, system monitoring, and machine-learning-based risk classification in one platform.

✨ Features

- 🌐 Network Scanning using Nmap
- 🔎 Website Security Analysis
- 💻 System Monitoring
- 🤖 Random Forest Risk Classification
- 🖥️ Django Web Interface
- 📊 Scan History Management

🛠️ Tech Stack

Python • Django • Nmap • Scikit-learn • Requests • psutil • Linux

⚙️ Installation

git clone https://github.com/thennarasu-n/TRISCAN.git
cd TRISCAN
chmod +x install.sh run.sh
./install.sh
./run.sh

⚠️ Disclaimer

For educational purposes and authorized security testing only. Always obtain permission before scanning systems or websites.
